Colors

Usage

CSS
.my-banner {
  background: color-mix(in srgb, var(--fx-color-primary) 10%, transparent);
  border-inline-start: 3px solid var(--fx-color-primary);
  color: var(--fx-color-text);
}
Dark mode does not invert colors — it swaps the neutral palette for dedicated darker surfaces and slightly brightens semantic hues for contrast.
