JavaScript API

One global namespace (Fluxa), modular methods, declarative hooks. All methods are importable as ES modules too.

Global object

JavaScript
Fluxa.version           // "1.0.0"
Fluxa.init(document)    // re-scan subtree for declarative components
Fluxa.announce('msg')   // screen-reader live region
Fluxa.lockScroll()      // + Fluxa.unlockScroll()

Declarative hooks

AttributeBehavior
data-fx-modal="#id"Open modal on click
data-fx-drawer="#id"Open drawer on click
data-fx-dropdown="#menuId"Toggle external dropdown menu
data-fx-popover="#id"Toggle a popover
data-fx-context="#menuId"Right-click context menu
data-fx-tooltip="text"Tooltip on hover/focus
data-fx-commandOpen command palette (Ctrl/⌘ K too)
data-fx-toast + variantsShow a toast on click
data-fx-theme-toggleToggle light/dark
data-fx-sidebar-toggleToggle mobile sidebar overlay

ES modules

JavaScript
import { Fluxa } from 'fluxa-ui';
// or only what you need:
import { Modal, Toast, Theme } from 'fluxa-ui';

Modal.open('#signup');
Toast.success('Welcome!');
Theme.set('dark');

Events

fx:opened / fx:closed — overlays (bubble on the root element)
fx:select — combobox selection, with event.detail.value
fx:theme — fired on document with the new theme
fx:ready — fired once when Fluxa finishes booting
