Quick start

From an empty HTML file to your first interactive component in under a minute.

1. Link the files

HTML
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="https://unpkg.com/fluxa-ui@1.0.0/dist/fluxa.css">
</head>
<body>
  <!-- your content -->
  <script src="https://unpkg.com/fluxa-ui@1.0.0/dist/fluxa.js" defer></script>
</body>
</html>

2. Add components

Live

Hello, Fluxa

Your first declarative modal.

Add data-fx-modal="#id" to any element and it becomes a trigger. Escape, backdrop click and the close button all work.
HTML
<button class="fx-btn fx-btn-primary" data-fx-modal="#my-modal">
  Open modal
</button>

<div class="fx-modal" id="my-modal">
  <div class="fx-modal-backdrop"></div>
  <div class="fx-modal-panel">
    <div class="fx-modal-header">
      <h2 class="fx-modal-title" id="my-modal-title">Hello, Fluxa</h2>
    </div>
    <div class="fx-modal-body">…</div>
    <div class="fx-modal-footer">
      <button class="fx-btn fx-btn-ghost" data-fx-modal-close>Close</button>
    </div>
  </div>
</div>

3. Use the JavaScript API

JavaScript
Fluxa.Modal.open('#my-modal');
Fluxa.Toast.success('Saved successfully');
Fluxa.Dropdown.closeAll();

// custom command palette
Fluxa.Command.open({
  groups: [{
    label: 'Actions',
    items: [{
      label: 'Toggle dark mode',
      action: () => Fluxa.Theme.toggle()
    }]
  }]
});

4. Dark mode

Set an explicit theme on <html> — or omit it to follow the operating system automatically.

HTML
<html data-theme="dark">   <!-- or "light", or nothing = system -->
