Accessibility

Accessibility is a build requirement, not a feature. Here is everything Fluxa ships out of the box.

Built-in

Focus traps on modals, drawers, command palette
Roving tabindex + arrow-key navigation in tabs, menus, combobox
Escape to close every overlay, with focus restoration
Visible focus rings via :focus-visible
aria-expanded, aria-controls, aria-selected, aria-modal on interactive roles
Screen-reader live region for toasts and announcements
prefers-reduced-motion disables animation & transition
.fx-sr-only / .fx-skip-link helpers

Reduced motion

Users who request reduced motion get instant, unanimated interactions — the content still appears and works.

CSS
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

Contrast

Primary, success and danger fills keep white-text contrast at AA for normal text (≥ 4.5:1). Warning uses dark text, which comfortably passes AA.

Form accessibility

Every form control uses real labels. Use .fx-form-field for label + control + hint associations.
