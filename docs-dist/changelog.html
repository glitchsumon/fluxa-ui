Components — button, card, forms, select, checkbox, radio, switch, badge, avatar, alert, toast, modal, drawer, dropdown, tooltip, popover, tabs, accordion, breadcrumb, pagination, table, progress, spinner, skeleton, navbar, sidebar, command palette, stepper, combobox, slider, uploader, list, timeline, stats, empty state.
Motion — "Edge Motion" interaction language and a reduced-motion safe motion system.
Themes — light and dark with system-preference fallback and persistence.
JS — modular vanilla components, declarative data-fx-* hooks, full API surface.
Docs — full documentation site and dashboard demo.
