Installation

Add Fluxa UI to any project — via npm, a CDN or a plain .css / .js pair. No build step is required.

Package managers

Terminal
# npm
npm install fluxa-ui

# pnpm
pnpm add fluxa-ui

# yarn
yarn add fluxa-ui

The package ships compiled dist/fluxa.js (ES module + UMD) and dist/fluxa.css (minified).

Import in your source

CSS
/* main.css */
@import "fluxa-ui/dist/fluxa.css";
JavaScript
import { Fluxa } from 'fluxa-ui';

// declarative components auto-initialize;
// programmatic API is available too
Fluxa.Toast.success('Ready');

CDN

The fastest path for prototypes and static sites. Use the latest release tag.

HTML
<link rel="stylesheet"
      href="https://unpkg.com/fluxa-ui@1.0.0/dist/fluxa.css">

<script src="https://unpkg.com/fluxa-ui@1.0.0/dist/fluxa.js" defer></script>
The UMD build exposes a global Fluxa object (e.g. window.Fluxa.Toast.success('hi')).

Static files

Download the two production files and link them locally:

HTML
<link rel="stylesheet" href="css/fluxa.css">
<script src="js/fluxa.js" defer></script>
