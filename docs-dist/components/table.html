Variants & accessibility

fx-table-compact tightens padding for dense data.
fx-table-striped for alternating row shading at high data density.

Selection relies on a class, not color alone — pair with a checkmark or aria-pressed where actions exist.
Use real <th scope="col"> for column headers.
