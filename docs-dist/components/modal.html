Modal

Keyboard-first dialogs. Focus is trapped, page scroll locks, and Esc closes the top-most overlay only.

Sizes

fx-modal-sm — compact, max-width 22rem.
fx-modal-lg — detail views, max-width 42rem.
fx-modal-xl — wide contexts, max-width 56rem.
HTML
<div id="modal-x" class="fx-modal fx-modal-lg" role="dialog" …>…</div>

Keyboard & API

Esc closes the top-most overlay only — nesting is safe.
Tab / Shift+Tab cycle inside the panel.
Closing restores focus to the element that opened it.
Programmatic: Fluxa.modal.open('#id') and Fluxa.modal.close('#id').
Confirm reset
This action cannot be undone.

This will remove all local content and reset preferences to the defaults. You can restore from a backup within 30 days.
