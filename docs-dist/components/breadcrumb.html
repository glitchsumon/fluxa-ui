Docs Components Breadcrumb

<nav class="fx-breadcrumb" aria-label="Breadcrumb">
  <span class="fx-breadcrumb-item">
    <a href="/docs">Docs</a>
  </span>
  <span class="fx-breadcrumb-item">
    <a href="/docs/components">Components</a>
  </span>
  <span class="fx-breadcrumb-item" aria-current="page">Current</span>
</nav>

Pagination

HTML
<nav class="fx-pagination" aria-label="Pagination">
  <button class="fx-btn fx-btn-sm" disabled>Previous</button>
  <button class="fx-pagination-item" aria-current="page"
          aria-label="Page 1">1</button>
  <button class="fx-pagination-item" aria-label="Page 2">2</button>
  <span class="fx-pagination-ellipsis">…</span>
  <button class="fx-btn fx-btn-sm">Next</button>
</nav>

Notes

aria-current="page" marks the current position — it carries the emphasis styling.
Separators are optional SVG .fx-breadcrumb-icon elements if you want a glyph between items.
