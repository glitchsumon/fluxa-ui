Accordion

Expandable sections using the disclosure pattern. Heights animate without layout jank; the chevron rotates as the edge underline draws in.

Demo

Stable at rest, alive on interaction. Edges, arrows and indicators carry the motion — backgrounds stay calm.

Yes. The core is presentational and progressively enhanced. Interactive primitives layer on top of semantic markup.

Tokens, blocks and the interactive layer all carry API boundaries. Override the whole thing under your own theme.

HTML
<div class="fx-accordion">
  <div class="fx-accordion-item" data-fx-open>
    <h3 class="fx-accordion-header">
      <button class="fx-accordion-trigger" aria-expanded="true"
              aria-controls="panel-1">Question…</button>
    </h3>
    <div class="fx-accordion-content" id="panel-1">
      <div class="fx-accordion-content-inner">…</div>
    </div>
  </div>
</div>

Notes

data-fx-multiple keeps other panels open when one toggles.
Default is single-open (like a real accordion).
Mark an item with data-fx-open to start it expanded.
