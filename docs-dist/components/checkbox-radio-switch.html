Checkbox · Radio · Switch

Custom-styled form controls built on native inputs — fully keyboard- and screen-reader friendly.

Checkbox

HTML
<label class="fx-checkbox">
  <input type="checkbox" checked />
  <span class="fx-checkbox-box">
    <svg class="fx-check" viewBox="0 0 24 24" fill="none"
         stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
      <path d="M20 6L9 17l-5-5"/>
    </svg>
  </span>
  <span class="fx-checkbox-label">Send weekly digest</span>
</label>

Switch

HTML
<label class="fx-switch">
  <input type="checkbox" checked />
  <span class="fx-switch-rail"><span class="fx-switch-thumb"></span></span>
  <span class="fx-switch-label">Notifications</span>
</label>

Notes

Native inputs stay in the accessibility tree — no ARIA scaffolding needed.
Focus rings appear via input:focus-visible + .fx-….
The checkbox check "draws" itself in (stroke-dashoffset) — pure CSS motion.
