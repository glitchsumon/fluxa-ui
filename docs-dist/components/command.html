Command palette

On-screen Ctrl+K search with arrow navigation, Home/End, and data-driven groups. The palette builds its own markup, so you wire data — not DOM.

Demo

or press Ctrl K
HTML + JS
<!-- declarative — default actions -->
<button data-fx-command>Open palette</button>

<!-- fully data-driven -->
<script>
  Fluxa.command.open({
    groups: [
      {
        label: 'Actions',
        items: [
          { id: 'dark', label: 'Toggle dark mode', icon: '…', action: () => toggle() },
          { id: 'pages', label: 'Go to dashboard', hint: 'G D', action: () => nav() }
        ]
      }
    ]
  });
</script>

<!-- global shortcut is bound automatically: Ctrl/⌘ + K -->

Item model

Each item: id · label · hint · keywords · icon (inline SVG string) · action.
Filtering is substring match across label, keywords and hint.
The generated surface is a focus-trapped overlay: Esc closes, click outside closes too.
API: Fluxa.command.open(config) · close() · toggle(config).
