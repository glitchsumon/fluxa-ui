Tooltip · Popover

Floating helpers positioned with a shared placement engine that flips and shifts to stay in view.

Tooltips

HTML + JS
<button class="fx-btn" data-fx-tooltip="Save changes"
        data-fx-placement="top">Save</button>
<!-- auto-initialized by registry -->

<!-- programmatic -->
<script>
  Fluxa.tooltip.attach(el, { content: 'Save', placement: 'right' });
  Fluxa.popover.open(anchor, panel, { placement: 'bottom' });
</script>

Popover

HTML
<button data-fx-popover="#popover">Open popover</button>

<div id="popover" class="fx-popover">
  <div class="fx-popover-header">
    <div class="fx-popover-title">Popover title</div>
    <button class="fx-popover-close" aria-label="Close">…</button>
  </div>
  <div class="fx-popover-body">…</div>
</div>
Popover title
Placement-aware content. Closes on outside interaction, stays put for inside clicks. The arrow follows the anchor.

Notes

Tooltips are role="tooltip" with no keyboard focus — they are a visual supplement, never the only way to know something.
Popovers reachable via tab should pair with aria-expanded on the trigger.
Placement options: top right bottom left; auto-flips at viewport edges.
