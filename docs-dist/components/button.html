States & accessibility

Default · Hover · Active · Focus-visible · Disabled — all styled with transition tokens.
Use real <button> or <a role="button"> with a href.
Never disable with only CSS — use the disabled attribute; it removes pointer interaction and is announced by screen readers.
Icon-only buttons need an aria-label.
Focus ring uses :focus-visible — keyboard users see it, mouse users don't.
