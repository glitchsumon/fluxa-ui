Toast

Transient notices stacked in a live region. Auto-dismissing, dismissible on demand, and announced without hijacking the reader's current context.

Demo

HTML + JS
<button data-fx-toast="Saved"
        data-fx-toast-type="success"
        data-fx-toast-body="Your changes are live.">Success</button>

<script>
  Fluxa.toast.show({
    title: 'Saved',
    body: 'Your changes are live.',
    type: 'success',
    duration: 4200
  });
  // or the shorthands:
  Fluxa.toast.success('Saved');
  Fluxa.toast.danger('Deploy failed', 'Check the pipeline logs.');
</script>

Options & notes

Options: title · body · type (success|info|warning|danger) · duration · onClose.
Each toast is role="status" inside one shared live region so readers announce once, non-interruptingly.
Hover to pause is available on your side — the default duration counts down from duration.
