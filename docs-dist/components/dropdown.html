Dropdown · Menu

Menus anchored to a trigger with arrow-key navigation, type-to-jump and Enter-to-select. Two markup conventions cover most layouts.

Container mode

HTML
<div class="fx-dropdown">
  <button class="fx-btn fx-dropdown-trigger"
          aria-haspopup="menu">Actions …</button>
  <div class="fx-dropdown-menu fx-menu" role="menu">
    <button class="fx-menu-item" role="menuitem">Duplicate</button>
    <div class="fx-menu-divider"></div>
    <button class="fx-menu-item fx-menu-item-active"
            role="menuitem">Delete</button>
  </div>
</div>

External trigger & context

HTML
<!-- panel anywhere else in the document -->
<button data-fx-dropdown="#notes-menu">Notes</button>
<div id="notes-menu" class="fx-menu" role="menu">…</div>

<!-- right-click / contextmenu key -->
<div data-fx-context="#row-menu">…row…</div>

Keyboard

ArrowUp / ArrowDown rove between items; Home / End jump.
Type characters to move to the next item starting with them.
Enter activates the highlighted item; Esc closes and returns focus.
