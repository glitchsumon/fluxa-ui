Tabs

Section switching with a sliding underline. WAI-ARIA tabs pattern — arrows move the roving focus, Home/End jump, activation follows focus. The underline is a pure scaleX transform, so it never reflows.

HTML
<div class="fx-tabs">
  <div class="fx-tablist" role="tablist" aria-label="…">
    <button class="fx-tab" role="tab" id="tab-overview"
            aria-controls="panel-overview" aria-selected="true">Overview</button>
    <button class="fx-tab" role="tab" id="tab-activity"
            aria-controls="panel-activity" aria-selected="false"
            tabindex="-1">Activity</button>
  </div>
  <div class="fx-tabpanel" role="tabpanel" id="panel-overview"
       aria-labelledby="tab-overview">…</div>
  <div class="fx-tabpanel" role="tabpanel" id="panel-activity"
       aria-labelledby="tab-activity" hidden>…</div>
</div>

Variants & API

fx-tabs-pills — rounded highlight instead of the traveling underline.
fx-tabs-lined — hairline across the whole tab strip.
fx-tabs-vertical — vertical tab rail on the start edge.
Programmatic: Fluxa.tabs.activate(tablist, index).
