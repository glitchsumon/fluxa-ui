Slider · Uploader

Range input theming and a dropzone-style file picker — both progressive enhancements over native semantics.

Slider

HTML
<label class="fx-form-label" for="budget">Budget</label>
<input id="budget" class="fx-slider" type="range"
       min="0" max="100" value="42" />

Uploader

Drop files here or click to browse

PNG, JPG, SVG up to 10 MB

HTML
<div class="fx-uploader-wrap">
  <div class="fx-uploader" role="button" tabindex="0">
    <span class="fx-uploader-icon">…</span>
    <p class="fx-uploader-title">Drop files here</p>
    <p class="fx-uploader-hint">PNG, JPG, SVG up to 10 MB</p>
  </div>
  <input type="file" class="fx-sr-only" />
  <div class="fx-uploader-filelist"></div>
</div>

Notes

The slider fills its track via --fx-slider-fill; pair data-fx-slider-display with an output element for live values.
The uploader is keyboard operable (Enter/Space) and handles drag events; it exposes the change event so you wire your own upload.
Add fx-uploader-multiple and multiple for multi-file mode.
