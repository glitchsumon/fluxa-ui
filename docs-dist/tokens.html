Design tokens

Every value in Fluxa UI flows from CSS custom properties. Tokens keep the framework consistent and make theming a single-source-of-truth change.

Tokens are grouped into a raw palette (physical values) and a semantic layer (what components consume). Override the semantic layer to re-theme the framework without touching components.

Customizing

Override tokens in a layer after the framework, or fork the token file. Example:

CSS
:root {
  --fx-color-primary: #334155;   /* your brand color */
  --fx-radius-md: 10px;          /* your corner style */
  --fx-space-4: 18px;            /* your rhythm */
  --fx-font-sans: 'Space Grotesk', system-ui, sans-serif;
}

:root[data-theme='dark'] {
  --fx-palette-surface: #0b0d12; /* dedicated dark surface */
}
