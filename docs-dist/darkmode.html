Dark mode

Dark mode reuses the same design language with dedicated surfaces, borders and slightly lighter semantic accents. No inverted colors, no blind replacements.

Toggle it

How it works

The theme is driven by a data-theme attribute on <html>. Token values switch inside :root[data-theme='dark']. If no attribute is present, the framework follows prefers-color-scheme.

HTML
<html data-theme="light">  <!-- force light -->
<html data-theme="dark">   <!-- force dark -->
<html>                       <!-- follow the OS -->

Persist the choice

JavaScript
// stored in localStorage['fx-theme'] automatically
Fluxa.Theme.set('dark');
Fluxa.Theme.set('light');
Fluxa.Theme.set('system');

const current = Fluxa.Theme.get();     // 'dark' | 'light' | 'system'
const next = Fluxa.Theme.toggle();     // flips & returns the new value

Designing dark surfaces

Four surface levels give the dark theme its structure, from page background up to raised overlays:

--fx-color-bg
--fx-color-surface
--fx-color-surface-raised
--fx-color-border
