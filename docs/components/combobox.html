Combobox

An input that filters a shared menu surface. Arrows move, Enter selects, Esc closes; role="combobox" and aria-activedescendant keep assistive tech in the loop.

Demo

HTML
<div class="fx-combobox">
  <div class="fx-combobox-input-wrap">
    <input class="fx-input" data-fx-combobox-input
           type="text" placeholder="Search…" />
    <button class="fx-combobox-chevron" tabindex="-1">…</button>
  </div>
  <div class="fx-menu" role="listbox">
    <button class="fx-menu-item" role="option"
            data-value="Vue">Vue</button>
  </div>
</div>

Notes

data-fx-combobox-input marks the field; options reuse .fx-menu-item with role="option" and data-value.
Add data-fx-multiple for tag-style multi-select rendered into .fx-combobox-tags.
Selecting fires a bubbling fx:select event with the value in detail.
