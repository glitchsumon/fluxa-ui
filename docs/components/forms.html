Validation state

Looks good — available.

Slug can't contain spaces. Suggestion: fluxa-ui.

HTML
<input class="fx-input fx-input-error" type="text"
       aria-invalid="true" aria-describedby="slug-err" />
<p id="slug-err" class="fx-form-error">
  Slug can't contain spaces.
</p>

Notes

States: fx-input-error / fx-input-success on the field, message text beside it.
Validation is always message + icon/border + aria-invalid — never color alone.
The focus ring stays visible in both themes; it is the marker of interactivity.
