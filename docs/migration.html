Migration

Guidance for adopting Fluxa UI in an existing project — from another framework or a hand-rolled codebase.

From another CSS framework

Add Fluxa's stylesheet and script alongside the existing setup first.
Migrate page by page; both can coexist during the transition.
Fluxa's namespace (fx-*) won't collide with Bootstrap/Tailwind/Foundation classes.
Map your old classes: btn → fx-btn fx-btn-secondary, card → fx-card.
Port over custom component CSS into the token layer (--fx-color-*, --fx-space-*).

Versioning policy

Minor — backwards-compatible additions and new components.
Major — breaking class or API changes, always listed in the changelog with a codemod-style guide.
