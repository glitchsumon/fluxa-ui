Fluxa UI v1.0

A component framework with a
Structured Motion design language

Build modern, premium interfaces with a distinctive visual identity. No Bootstrap. No Tailwind. No framework lock-in — just clean, accessible, production-ready CSS and a tiny vanilla JavaScript layer.

Get started Browse components
npm i fluxa-ui · 14.4 kB gzipped CSS · zero runtime dependencies

Original identity

A carefully designed visual language that doesn't look like any existing framework. Square-soft radii, layered surfaces and a restrained violet-indigo accent.

Fast by default

Every micro-interaction uses transforms and opacity only. Motion is short, functional and respects prefers-reduced-motion.

Accessible everywhere

ARIA patterns, roving tabindex, focus traps, live regions and full keyboard support ship in every interactive component.

Zero dependencies

Pure CSS custom properties and vanilla JavaScript. Works without a build step or with your favorite bundler.

Predictable API

fx-component · fx-component-variant · fx-utility. One naming system across the whole framework.

A complete system

Twenty-five components, a full token system, dark mode, utilities and a dashboard demo — everything a real product needs.
