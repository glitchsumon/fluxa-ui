Fonts

Fluxa ships with a tuned system stack — nothing to download. Docs use the same stack; swap --fx-font-sans to adopt a custom font:

CSS
:root {
  --fx-font-sans: 'Inter', system-ui, sans-serif;
  --fx-font-mono: 'JetBrains Mono', ui-monospace, monospace;
}
